# Подключение к gramsrv

Эта сборка подключается к серверу gramsrv на домашнем Windows-ПК:

| Параметр | Значение |
| --- | --- |
| Публичный адрес | `188.227.220.178` |
| TCP-порт | `2398` |
| Основной DC | `2` |
| Код входа в режиме разработки | `12345` |
| Назначение проброса порта на роутере | `192.168.1.81:2398/TCP` |

Внешний IP проверен 18 октября 2026 года. При изменении IP нужно поменять
`publicServerHost` в `submodules/TelegramCore/Sources/Network/Network.swift`
и пересобрать приложение. Вместо IP можно указать домен, направленный на сервер.

В `Network.swift` DC 1–5 направлены на этот backend до создания `MTContext`.
Это относится к обычным подключениям и загрузке медиа. Резервный поиск адресов
Telegram через DNS/iCloud отключён. Первоначальный DC в `Account.swift` — `2`.

Публичный RSA-ключ сервера закреплён в двух файлах MtProtoKit:

- `submodules/MtProtoKit/Sources/MTDatacenterAuthMessageService.m`;
- `submodules/MtProtoKit/Sources/MTEncryption.m`.

При смене серверной RSA-идентичности нужно обновить обе копии ключа и пересобрать
клиент. Закрытый ключ в исходники клиента добавлять не нужно.

## Подготовка сервера

На ПК сервер должен слушать `0.0.0.0:2398`, а `TELESRV_ADVERTISE_IP` должен быть
равен `188.227.220.178`. Пробросить TCP-порт 2398 на `192.168.1.81:2398` и
разрешить входящий TCP 2398 в брандмауэре Windows. Локальный адрес ПК желательно
закрепить в DHCP роутера. Порты базы данных, Redis и админ-панели для подключения
iOS-клиента не нужны.

Проверять внешний доступ удобно с iPhone через мобильную сеть: так результат
не зависит от поддержки NAT loopback роутером.

## Сборка

Собирать IPA нужно на macOS с Xcode и настройками подписи этого проекта.
Команды сборки и генерации Xcode-проекта приведены в `README.md`.
Изменение исходников не меняет уже установленное приложение: необходима новая
сборка IPA. После установки войти в аккаунт нашего сервера.
